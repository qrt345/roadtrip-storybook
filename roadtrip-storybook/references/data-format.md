# 行程数据格式 v1

构建输入是UTF-8 JSON。脚本验证结构与引用，不判断旅游事实真伪；所有展示文字都按纯文本转义，不接受HTML或JavaScript。输出文件名由输入文件名或 `--output` 决定。

## 顶层

| 字段 | 必填 | 含义 |
|---|---|---|
| `version` | 是 | 固定为1 |
| `id` | 是 | 每份旅行独立的小写英文、数字、连字符标识，供本地清单隔离 |
| `title` | 是 | 浏览器标题 |
| `brand` | 否 | 页眉名称，默认“一路有你” |
| `edition` | 否 | 页眉副标题 |
| `snapshot` | 否 | 资料日期或版本的文字；不自动当成核验日期 |
| `source_md` | 否 | 相对JSON所在目录的可分享MD，必须位于同目录或其子目录；原文嵌入HTML |
| `source_note` | 否 | 原文来源、核验边界或分享说明 |
| `theme` | 否 | `accent`、`ink`、`paper`、`map`，值为六位十六进制颜色 |
| `pages` | 是 | 至少1页，无固定天数或页数 |

## 一页

| 字段 | 必填 | 含义 |
|---|---|---|
| `id` | 是 | 同一本手账内唯一，与地图节点跳页关联 |
| `name` | 是 | 目录中简短页面名 |
| `chapter` | 否 | 日期或章节；连续同名页归为一个导航项 |
| `eyebrow` | 否 | 标题上方小字 |
| `title` | 是 | 字符串，或1—3个字符串组成的换行标题 |
| `accent_line` | 否 | 橘红强调的标题行，下标从0开始；不填写则不强调 |
| `lead`、`foot` | 否 | 导语、底部资料注记，支持文本换行 |
| `cover` | 否 | `true` 使用封面字号和开始按钮 |
| `metrics` | 否 | 数组，每项包含 `value`、可选 `unit`、`label` |
| `companions` | 否 | 数组，每项 `label` 和可选 `icon`；已知犬种可用 `bichon/poodle/dachshund/corgi`，普通图标可用 `dog/person/bag`；未提供宠物信息就不创建犬只头像 |
| `sections` | 否 | 数组，每项 `title` 与可选 `time`、`body`、`status` |
| `note` | 否 | 提示条文字 |
| `warning` | 否 | `true` 将提示条显示为醒目颜色 |
| `table` | 否 | `headers` 字符串数组；`rows` 二维字符串数组，每行列数一致 |
| `checklist` | 否 | 数组，每项唯一 `id` 和 `label`，用于当前页独立勾选；初始不代用户勾选 |
| `choices` | 否 | 备选数组，每项唯一 `id`、`label`，可含 `sections`、`note`、`map`；第一项默认展示，切换不代表实际决定 |
| `map` | 是 | 见下文；若某备选没有地图，沿用本页地图 |

`status` 可用 `confirmed` 已确认、`booked` 已预订、`planned` 计划、`pending` 待确认、`reference` 参考。标记应针对具体事实；例如“确定去夜场”与“夜场允许带狗”应分开写。

## 地图

- `title`：图上标题。
- `finish`：动画结束时的说明。
- `nodes`：非空数组，节点内 `id` 唯一，`label` 地点名称，`detail` 简短补充。
- 节点可选 `icon`：`house/tower/mountain/tree/fish/cup/charge/flag/hotpot/bag/sun`。
- 节点可选 `page`：目标页面的 `id`；让该地点可以点击跳转，构建时验证引用。
- 节点可选 `x/y`：SVG 720×640坐标内的位置，建议 `x=85—635`、`y=125—515`，必须成对提供。未填写时按节点数自动排布。自动布局最多8个节点；更多节点需要明确坐标，或拆分地图。
- 节点可选 `dx/dy`：相对节点的标签偏移；默认在下方。图标在节点上方。手工排列后必须看渲染，避免标签或图标相撞。
- `legs`：数组，每项 `from/to` 引用节点id，可选 `mode` 为 `car/walk/cable/train/boat`，默认car；`label` 在该段动画时显示。**不提供legs不会自动猜路线**。
- `optional: true`：画出较淡的备选连线，但不让标记自动沿该段走。
- 相邻动画段应连续；不连续路线会让标记直接跳到下一段起点，应拆页或清楚说明换乘/独立路线。

地图不提供车辆可达性的判断，步道和索道必须使用正确交通标记。读者打开成品时不需同目录的原MD，完整原文已经内嵌。

## 批量

准备一组 `inputs/*.json`，每份有唯一 `id`。各输入可以引用各自子目录的 `source.md`。所有文件先验证再生成；一个输入验证失败则这一批不生成输出。输出按JSON文件名生成对应HTML，大小写冲突或已存在文件默认报错。

示例中的人物、地名、数字均为展示测试，不应带入正式行程。脚本会嵌入JSON以便浏览器运行；分享前审阅整份数据和source_md，不能只检查首屏。
